# Open-Data Directory (Deutschland)

Lebendes Quellenverzeichnis für Landkreis-/Gemeinde- und Rasterdaten.
Pflege: Jarvis / Atlas (tetraeder.solar). Getrennt vom Branchenradar.

## Aufbau

- `quellen/dictionary.md` — Dictionary einzelner Datensätze und APIs (Kern, Updates, Nischen, Portale)
- `quellen/startliste.md` — Portale und Einstiege
- `crawls/` — belegte Crawl-Läufe mit Download-/API-URLs und Relevanz

## Scope

Nur Deutschland. Ebene Landkreis, Gemeinde oder Raster. Einträge brauchen Download- oder API-URL plus Relevanz für Dashboard/Ranking.

## Pflege

Neue Treffer zuerst in `crawls/YYYY-MM-DD*.md`, dann ins Dictionary übernehmen. Keine Secrets in diesem Repo.
